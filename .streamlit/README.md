# 📡 SOPHIA-IQ // PLEROMA SPECTRAL COMMAND

An AI-driven wideband Software Defined Radio (SDR) command center featuring full-spectrum frequency tuning (0.1–6000 MHz), dynamic signal parsing, browser audio playback, downloadable audio recordings, and high-res spectral screenshots.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `streamlit run app.py`
